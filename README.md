# FanPedia: An Intelligent Textbook on Fans & Blowers

An interactive intelligent textbook on industrial and commercial fans and blowers, built from
Twin City Fan's *FanPedia: The Fan & Blower Encyclopedia* and current Twin City Fan catalogs.

**Read it online: https://moroshek.github.io/FanTASTIC-textbook/**

This repository only hosts the published website (the `gh-pages` branch). The textbook's source
is maintained separately.
