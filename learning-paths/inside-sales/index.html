    Inside Sales and Customer Service¶

    This path is for you if you enter orders, prepare quotes or answer customer calls, and your job is to turn a request into an order line that is complete and consistent. It teaches you to read a Twin City Fan model code and performance table, to write arrangement, rotation, discharge and motor position correctly, and to check a full fan description before it goes to the plant.

    You do not need the physics of impeller design or sound for this work, so the path skips or skims those chapters. Follow the checklist in order: the early chapters give you the vocabulary that the catalog and order-entry chapters rely on.

    Target Concepts¶

    These are the concepts that define the job outcome for this path. Everything else on the path is a prerequisite of one of them in the learning graph.

    Concept Taught in Why it is on this path
    Model Code Ch. 26: Model Code Remember: name an example product line for each family; every order line starts from a catalog model code.
    Fan Size Ch. 26: Fan Size Analyze: break down a full fan description (type, size, arrangement ...) into its parts.
    Catalog Structure Ch. 26: Catalog Structure Topic 14: reading a current Twin City Fan catalog.
    Reading a Performance Table Ch. 26: Reading a Performance Table Apply: read a current catalog performance table to find the RPM and brake horsepower for a required airflow and static pressure.
    Catalog Operating Limits Ch. 26: Catalog Operating Limits Analyze: check that the parts of a description are consistent; a size, class and speed outside the catalog limits is not orderable.
    FanPedia vs Current Catalog Ch. 26: FanPedia Versus the Current Catalog Analyze: distinguish FanPedia guidance from current catalog data and identify which source governs.
    Fan Arrangement Ch. 11: The Fan Arrangement (opening) Remember: recall the standard arrangement numbers and which are direct drive and which belt drive.
    Rotation and Discharge Code Ch. 13: Rotation and Discharge Code (opening) Apply: write the complete rotation and discharge designation for a fan shown in a drawing.
    Motor Position Restrictions Ch. 13: Motor Position Restrictions Apply: determine which motor positions are allowed for a given discharge.
    Motor Nameplate Ch. 14: The Motor Nameplate Topic 7 (drive train components): the motor horsepower, enclosure, voltage and phase on an order come from nameplate data.
    Construction Class Ch. 20: Construction Class: Matching the Fan to Its Airstream Analyze: the construction class is one of the fields of a full fan description.
    Product Options Ch. 26: Product Options Remember: list common fan accessories (dampers, inlet boxes, drains, shaft seals, isolation bases).
    Complete Fan Description Ch. 27: Complete Fan Description Analyze: break down a full fan description into type, size, arrangement, rotation, discharge, motor position, construction class and accessories, and check that they are consistent.

    When You Finish¶

    Test your eye for a bad order line: run the Specification Error Detector, which asks you to mark each clause of a draft dryer exhaust fan specification acceptable or defective and say why. When customers start asking which product fits their job, continue with the Outside Sales and Manufacturer's Representatives path; the chapters you have already read are marked there too.
