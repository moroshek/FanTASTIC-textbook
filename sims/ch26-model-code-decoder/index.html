    Model Code Decoder¶

    Run the Model Code Decoder MicroSim Fullscreen

    This sketch is built on the FanPedia MicroSim kit. To run it in the p5.js editor, add the ../shared-libs/ files it loads (fanpedia-sim.css, fanpedia-core.js, fanpedia-p5.js), or their published URLs, to the editor's index.html before pasting ch26-model-code-decoder.js.

    About This MicroSim¶

    A designation names one buildable fan: model, size, class and arrangement, such as "RBA 913, Class 22, Arrangement 10". For each of eight designations the learner commits two answers:

    • Offered or Not offered. Offered when the arrangement appears in the list for that model, size and class; Not offered otherwise, including when the class is not built for that size.
    • Class maximum RPM. The value in the extract for that class, chosen from the values in that model's row, or "none" when the class is not built.

    A designation is correct only when both answers match. Two catalog extracts can be opened and closed at any time (they start collapsed):

    • Extract A, Catalog 902 (November 2017): RB Series availability (page 13) and maximum RPM (pages 20 and 24) for RBO 905 (8.75 in. impeller, Class 22 only) and RBA 913 (22.625 in. impeller, Classes 22, 32 and 45: 2,812, 3,337 and 4,000 RPM).
    • Extract B, Catalog 300 (April 2024): arrangements by model (pages 2-3 and 9) and maximum RPM by class (page 16) for BC-SW 365 and BC-DW 365.
    # Designation Offered? Class maximum RPM
    1 RBA 913, Class 22, Arrangement 10 Offered 2,812
    2 RBA 913, Class 32, Arrangement 10 Not offered 3,337
    3 RBA 913, Class 45, Arrangement 4 Not offered 4,000
    4 RBA 913, Class 45, Arrangement 9 Offered 4,000
    5 RBO 905, Class 22, Arrangement 9A Offered 5,296
    6 RBO 905, Class 32, Arrangement 1 Not offered none
    7 BC-SW 365, Class II, Arrangement 9 Offered 1,283
    8 BC-DW 365, Class I, Arrangement 9 Not offered 1,015

    The designations come in this fixed order, the first three matching the chapter's worked example. Each has one scored attempt. A correct answer reads "✓ Correct:" with the reason. A wrong one names which of the two answers was wrong, gives the reason, marks each answer ✓ right or ✗ wrong, and allows one Practice try that is never scored; the practice feedback gives the full answer. The score reads "Designations correct: n of 8"; mastery is 7 of 8 on the first attempt. After the eighth designation the summary lists every missed designation with its answer. Start over clears the score.

    How to Use¶

    1. Read the designation, then open the extract that covers its model.
    2. Find the row for the model and size, then the list for the class. Is the arrangement in it?
    3. Choose Offered or Not offered, choose the class maximum RPM (or none if the class is not built for this size), and press Check.
    4. Read the feedback. After a miss, change your answers and press Practice try if you want an unscored second look. Press Next designation to continue; after the eighth, read the summary.

    Keyboard: O chooses Offered and N Not offered; keys 1 to 5 choose a maximum RPM button from the left; Enter checks, then goes to the next designation (and starts over from the summary); A and B open or collapse the extracts. After a shortcut key chooses both answers, focus moves to Check. Tab and Space or Enter work on every button.

    Data label: "Source: TCF Catalog 902 (Nov 2017) pp. 13, 20, 24; Catalog 300 (Apr 2024) pp. 2-3, 9, 16", shown at the bottom left of the drawing.

    Lesson Plan¶

    Learning Objective¶

    The learner will interpret a Twin City Fan designation (model code, size, class, arrangement) by judging whether it is offered and reading its class maximum RPM from catalog extracts, for at least 7 of 8 designations (Bloom: Understand, verb: interpret).

    Audience¶

    Adult professional development: new application engineers, sales staff, representatives and facilities staff.

    Duration¶

    10-15 minutes

    Prerequisites¶

    Model code, fan size, fan class, arrangement and maximum RPM, defined in the sections "Fan Size" and "Model Code" of Chapter 26 and in Chapter 10 and Chapter 11.

    Activities¶

    1. Decode (6 min): Judge all eight designations. Say which table row and which class list you used before pressing Check.
    2. Review (3 min): Compare designations 1 and 2: same model, size and arrangement, different class. Compare 7 and 8: same size number in two models of the same catalog.
    3. Discuss (3 min): A customer insists on a Class 45 RBA 913 in Arrangement 4. What do you offer instead, and why?

    Common Misconceptions Addressed¶

    • If a size is offered in a class and an arrangement is offered in the line, every combination is offered: designations 2 and 3 use arrangements the line offers, in classes that do not list them.
    • A direct-drive arrangement is available in every class: designation 3 (Arrangement 4 at Class 45) is not offered.
    • A size number means the same diameter in every model: Extract A shows size 905 at 8.75 in. and 913 at 22.625 in.; BC-SW 365 and BC-DW 365 have different arrangement lists and maximum speeds.

    Assessment¶

    • Score "Designations correct: n of 8"; mastery is 7 of 8 on the first attempt. Practice tries are not evidence of mastery.
    • Follow-up question: why does designation 2 still have a class maximum RPM answer (3,337) when the designation is not offered?

    References¶

    1. Chapter 26: Reading Catalogs and Performance Tables - fan size, model code and the "Is This Designation Buildable?" worked example.
    2. Twin City Fan Catalog 902, RB Industrial Fans (PDF) - RB Series Availability (page 13) and performance pages 20 and 24.
    3. Twin City Fan Product Catalogs - Catalog 300 (BC backward inclined fans, April 2024), pages 2-3 and 9 arrangements by model (page 3's BC-DW list omits Arrangement 7, which page 2 lists and page 9 describes) and page 16 maximum RPM.
    4. p5.js - the JavaScript library used to draw the decoder.
